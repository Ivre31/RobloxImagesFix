# Roblox Images Fix

Небольшая бесплатная программа для Windows. Она проверяет, почему в Roblox не загружаются картинки (аватары, иконки игр, превью на главной), и пытается это исправить в один клик.

Проект не связан с компанией Roblox Corporation и не является её продуктом.

## Какая проблема решается

- Roblox открывается, игры запускаются, аккаунт работает, но вместо картинок серые плитки.
- Из десятков картинок видны только одна-две (те, что остались в кэше).
- Переустановка Roblox не помогает.

Об этой проблеме пишут пользователи из России. Причина в том, что компьютер не находит адрес `tr.rbxcdn.com`, с которого Roblox загружает изображения, или не может с ним соединиться. Остальные части Roblox при этом работают.

## Скачать и запустить

1. Откройте раздел **Releases** на странице репозитория и скачайте `RobloxImagesFix.exe`.
2. Запустите файл и подтвердите запрос прав администратора. Они нужны, чтобы менять настройки сети.
3. Подождите несколько секунд: программа сама проведёт проверку. Если она предложит исправление, нажмите **Исправить автоматически**.
4. Полностью закройте Roblox и браузер и откройте заново.

Повторять исправление не нужно: настройки сохраняются и после перезагрузки.

## Что программа делает на вашем компьютере

Изменения вносятся только после нажатия кнопки **Исправить автоматически**:

1. Один раз сохраняет ваши прежние настройки DNS в `C:\ProgramData\RobloxImagesFix\dns-backup.txt`.
2. Меняет DNS на физических сетевых адаптерах (Wi-Fi, Ethernet): сначала OpenDNS, затем Cloudflare, затем Google, пока адреса Roblox не начнут находиться. Используется команда `netsh interface ipv4 set dnsservers`.
3. Если не помогло, включает шифрованный DNS (DNS over HTTPS) для этих серверов командой `netsh dns add encryption`. Эта команда есть в Windows 11.
4. Если и это не помогло, проверяет несколько известных адресов серверов CloudFront. Если сервер отвечает по защищённому соединению с проверкой сертификата для нужного имени, добавляет в файл `hosts` одну строку для `tr.rbxcdn.com` с пометкой `# RobloxImagesFix`. Другие строки в `hosts` программа не трогает.
5. Очищает кэш DNS командой `ipconfig /flushdns`.

Программа не собирает и не отправляет никаких личных данных. Она обращается к серверам Roblox для проверки соединения и спрашивает адрес `tr.rbxcdn.com` у публичных DNS-сервисов Cloudflare (1.1.1.1) и Google (8.8.8.8), чтобы понять, подменяется ли ответ системного DNS.

## Как вернуть всё как было

Откройте **Показать подробности** и нажмите **Вернуть как было**. Программа вернёт сохранённые настройки DNS, отключит шифрованный DNS и удалит свои строки из `hosts`.

Вручную:

1. Нажмите `Win + R`, введите `ncpa.cpl`, откройте свойства адаптера, затем "IP версии 4" и выберите "Получить адрес DNS-сервера автоматически" (или верните свои адреса).
2. Удалите из `C:\Windows\System32\drivers\etc\hosts` строки с `# RobloxImagesFix`.
3. В командной строке от имени администратора выполните для каждого адреса `netsh dns delete encryption server=АДРЕС`, где адрес: `208.67.222.222`, `208.67.220.220`, `1.1.1.1`, `1.0.0.1`, `8.8.8.8`, `8.8.4.4`.
4. Удалите папку `C:\ProgramData\RobloxImagesFix`.

## Ограничения

- **Помогает не всем.** Если провайдер блокирует сами соединения с серверами картинок, никакие настройки DNS не помогут. Программа в этом случае прямо пишет об этом и показывает, какой адрес не отвечает.
- **VPN-расширение в браузере.** Если картинки пропадают только при включённом VPN, добавьте `roblox.com` и `rbxcdn.com` в исключения расширения. Программа проверяет подключение компьютера, а не браузера.
- **Шифрованный DNS** включается только в Windows 11. В Windows 10 этот шаг будет пропущен.
- **Запись в `hosts` закрепляет конкретный адрес сервера.** Адреса CDN могут измениться. Если картинки снова пропали, запустите программу и нажмите исправление ещё раз. Список адресов находится в переменной `CdnCandidates` в `src/RobloxImagesFix.cs`.
- Рассчитана на Windows 10 и 11. Дополнительно ничего устанавливать не нужно: используется .NET Framework 4, который входит в систему.

## Антивирус и SmartScreen

Программа не подписана цифровой подписью и меняет сетевые настройки и файл `hosts`, поэтому SmartScreen или антивирус могут выдать предупреждение. Проверить, что вы запускаете именно то, что в репозитории:

- Исходный код открыт, он находится в одном файле `src/RobloxImagesFix.cs`.
- Релизный файл собирается автоматически в GitHub Actions из этого исходника. Контрольную сумму можно сверить:

  ```
  certutil -hashfile RobloxImagesFix.exe SHA256
  ```

  Результат должен совпасть со строкой в `SHA256SUMS.txt` из того же релиза.
- Можно собрать программу самому, см. ниже.

## Сборка из исходников

Нужен только Windows. Запустите `build.bat`, результат появится в `bin\RobloxImagesFix.exe`. Используется компилятор `csc.exe` из .NET Framework 4 (язык C# 5).

## English summary

Roblox Images Fix is a small Windows utility for the case when Roblox works but images (avatars, game icons, thumbnails) do not load because the host `tr.rbxcdn.com` cannot be resolved or reached. It checks the connection, and on request switches DNS (OpenDNS, Cloudflare, Google), enables DNS over HTTPS (Windows 11) and, as a last resort, adds a verified entry to the `hosts` file. Everything is reversible with the "Вернуть как было" (restore) button. No personal data is collected. Not affiliated with Roblox Corporation. MIT licensed. Build with `build.bat` (needs only Windows). Download `RobloxImagesFix.exe` from Releases.
